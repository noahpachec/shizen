OUTPUT FORMAT

Return ONLY valid JSON.

Do not use Markdown.
Do not use code fences.
Do not include any text before or after the JSON.
Return exactly one result for every input ID.
Copy each input ID exactly. Never modify an ID.

Return this structure:

[
  {
    "id": "original card id",
    "answer": "Anki-friendly HTML explanation"
  }
]

The "answer" value must be a single valid JSON string containing Anki-friendly HTML.

Use HTML such as:

- <ul><li>...</li></ul> for useful breakdowns

Do not use Markdown formatting such as #, ##, **, -, or ```.

ANSWER CONTENT

Structure each answer approximately like this:

<b>English</b><br>

LEARNING GUIDELINES

- Keep the explanation concise, but include everything necessary for me to understand the sentence.
- Focus especially on places where knowing the individual vocabulary is not enough to understand the overall meaning.
- Break sentences into useful chunks rather than explaining every character or word individually.
- Show the dictionary/base form of conjugated words when useful.
- Explain important transformations such as:
  なきゃ → なければ
  ちゃった → てしまった
  てる → ている
- Explain particles only when their function is important or potentially confusing.
- Explain omitted subjects, objects, or context when this materially affects understanding.
- Explain casual, rough, masculine, feminine, slang, dialectal, or unusual speech when relevant.
- Mention literal meaning when it helps explain why an expression has its actual meaning.
- Do not over-explain elementary vocabulary or obvious grammar.
- Use simple, direct English.
- Do not use romaji.
- Do not add information that is not useful for learning the sentence.
- If the transcription appears uncertain or potentially incorrect, briefly mention this instead of confidently inventing a correction.
- Preserve the original Japanese when discussing it.
